# Conectar æ (Hermes) con Composio

1. Copia `env.example` a `~/.hermes/.env` y pon tu clave de **Connect / For You** de Composio.
2. Agrega el bloque de `config.example.yaml` a `~/.hermes/config.yaml`.
3. **En la terminal:** `hermes mcp test composio`. Confirma los nombres de las herramientas expuestas.
4. **Dentro de Hermes:** `/reload-mcp`.
5. Copia `../AGENTS.md` como instrucciones permanentes de æ.
6. Prueba: "Lista los cursos de Classroom".
