# Módulo 4 · Construir, revisar y enseñar desde el celular

4 martes, 7 pm hora Texas, con micropráctica diaria por WhatsApp. **Pieza que deja:** un proyecto publicado en GitHub.

## Clase 1 · Git como historia
- Git es un cuaderno de versiones: permite comparar y recuperar cambios. Su historia también puede reescribirse, así que hay que cuidarla.
- **Tarea 1 (evalúa solo lo enseñado):** repo creado, `README.md` y tres commits con mensajes claros.

## Clase 2 · GitHub y colaboración
- Ramas, issues, pull requests y revisión respetuosa.
- **Tarea 2:** un PR propio y una revisión al repo de un compañero.

## Clase 3 · Programación agéntica
- **Acceso:** usar una sola herramienta, probada antes con una cuenta de alumno. GitHub en el navegador sirve para trabajar con el repo; el agente requiere acceso propio.
- **`AGENTS.md`:** instrucciones para las herramientas compatibles, siempre con permisos claros y revisión humana.
- **Tarea 3:** un commit hecho con ayuda del agente y una nota: qué aceptaste, qué corregiste y por qué.

## Clase 4 · Proyecto para mi comunidad
- Publicar con GitHub Pages y presentarlo en 3 minutos.
