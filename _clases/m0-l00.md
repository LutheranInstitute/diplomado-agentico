# Lección 00 · Construye tu presencia en internet

**æ · Ingeniería agéntica centrada en el humano**

🫵 + 🧠 + 📦 + 🌐

- 🫵 **Tú:** tus ideas, tu lógica, tu criterio y tu dirección.
- 🧠 **Hark Pro** (o tu agente): razona, genera código, itera y te asiste.
- 📦 **GitHub:** tu código con versiones, tu propiedad, tu colaboración.
- 🌐 **GitHub.io:** tu sitio público, tu distribución, que te encuentren.
- 🧬 **æ:** el lenguaje simbólico que une todo.

`HUMAN://ROOT → æ → HARK_PRO → GITHUB → GITHUB.IO → 🌎 ↺`

## Idea central
No necesitas escribir cada línea de código para ser el arquitecto de un sistema. Tú defines la lógica, eliges la dirección, evalúas lo que el agente construye y **decides qué se publica**.

> La IA puede ayudar a escribir el código. GitHub puede guardarlo. Pero el humano sigue siendo el arquitecto de la intención, la lógica y las decisiones.

## Caso de estudio: esta misma portada
La portada del diplomado se hizo así, con Hark Pro y GitHub:
1. **Idea:** una página de bienvenida para los alumnos.
2. **Agente:** Hark propuso el diseño y el código.
3. **Revisión humana:** el docente pidió cambios: letra más grande, tres pasos claros, "trae tu propio agente".
4. **GitHub:** cada cambio quedó como un commit con su mensaje.
5. **GitHub.io:** GitHub Pages la publicó en [lutheraninstitute.github.io](https://lutheraninstitute.github.io/).

Puedes ver cada paso en el [historial de commits](https://github.com/LutheranInstitute/lutheraninstitute.github.io/commits/main).

## Tu tarea
Toma **una idea**, usa la IA para construirla, guárdala en un repositorio de GitHub, publícala en tu propio GitHub.io y explica lo que aprendiste.

1. Crea tu repo con la [plantilla mi-diplomado](https://github.com/LutheranInstitute/mi-diplomado) → **Use this template**.
2. Pídele a tu agente un primer borrador de `index.md` para tu idea.
3. Revisa, corrige y haz commit.
4. Activa **Settings → Pages → rama main**. Tu sitio vive en `https://TU-USUARIO.github.io/mi-diplomado/`.
5. En `REFLEXION.md`, anota qué propuso el agente, qué cambiaste y por qué.

## Al graduarte podrás decir
**Esto aprendí. Esto construí. Esto publiqué. Esto puedo enseñar.**

No enseñamos a consumir internet. Enseñamos a ser sus arquitectos. 🍊
