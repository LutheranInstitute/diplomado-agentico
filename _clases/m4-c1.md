# Git como historia

## Idea central
Git es un cuaderno de versiones: permite comparar y recuperar cambios. Su historia también puede reescribirse, así que hay que cuidarla.

## Práctica
Tarea 1: repo creado, README.md y tres commits con mensajes claros.
