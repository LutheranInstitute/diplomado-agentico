# Clase 3 · GitHub para todos

## Idea central
GitHub es tu **cuaderno público con memoria**. Lo que aprendes con tu agente se guarda en un repositorio, cada cambio queda con fecha y nota, y con un botón se convierte en página web. Lo que hoy aprendes, mañana lo **enseñas**. Es para constructores de **3 a 103 años**: si sabes tocar una pantalla, puedes construir.

🫵 Tú → 🧠 Hark Pro → 📦 GitHub → 🌐 GitHub.io → 🌎 ↺

## Antes de clase (10 minutos)
1. Crea tu cuenta gratis en [github.com](https://github.com). Usa un nombre de usuario que puedas compartir con tu comunidad.
2. Activa la verificación en dos pasos (2FA). Guarda tus códigos de recuperación en un lugar seguro.
3. Opcional: baja [GitHub Mobile](https://github.com/mobile) en tu celular.

## Cinco palabras
- **Repositorio (repo):** una carpeta con historia.
- **Archivo `.md`:** texto sencillo con formato (Markdown).
- **Commit:** guardar un cambio con una nota de qué hiciste y por qué.
- **Plantilla / fork:** copiar el repo de alguien para empezar el tuyo.
- **Pages:** publicar tu repo como página en `tuusuario.github.io`.

## Práctica en clase (desde el celular)
1. **Tu repo.** Abre la [plantilla mi-diplomado](https://github.com/LutheranInstitute/mi-diplomado) → **Use this template** → *Create a new repository* → nómbralo `mi-diplomado` → público.
2. **Tu primera página.** Pídele a Hark Pro: *"Ayúdame a escribir el README de mi repo: quién soy, qué estoy aprendiendo y para quién."* Revisa, corrige y pega el texto en `README.md`.
3. **Tu primer commit.** Toca **Commit changes** y escribe una nota clara, por ejemplo: *"Mi presentación en el Diplomado"*.
4. **Publica.** *Settings → Pages → Branch: main → Save.* En 1 o 2 minutos tu página vive en `tuusuario.github.io/mi-diplomado`.
5. **Comprueba antes de confiar.** Abre tu página y revisa: ¿nombres bien escritos? ¿datos privados? ¿fechas y cifras correctas? Si algo falla, otro commit lo arregla.

## Ahora enséñalo (10 minutos)
La regla del multiplicador: **tú hablas, la otra persona toca.**
1. Busca a alguien de 3 a 103 años: un niño, un abuelo, un alumno o alguien de tu congregación. Con los más pequeños, ellos dictan y tocan; tú acompañas.
2. Guíalo con las cinco palabras y los pasos 1, 3 y 4. No tomes su celular.
3. Al terminar, pídele que te explique qué es un commit con sus palabras.
4. Anota en `REFLEXION.md`: qué entendió rápido, dónde se trabó y qué dirías distinto.

## Reglas de la clase
- Un repo público lo puede ver **todo el mundo**. Nada de datos de alumnos, feligreses ni clientes.
- **Nunca** pongas contraseñas, tokens ni llaves en un archivo.
- Hark Pro prepara; **tú haces el commit**. La evidencia no es autoridad.
